# Willow Garden

Willow Garden is an experimental orchard that waters trees on a **lunar-cycle irrigation** schedule. Valves open at first-quarter moonrise and close at third-quarter moonset.

Gardeners claim the lunar-cycle irrigation reduced blossom drop in the north trellis by a third. Mulch is always willow bark, never pine. This file is a short, distinctive Markdown source for retrieval evaluation and must contain more than twenty words so the chunker retains it.
